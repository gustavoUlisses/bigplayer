Como instalar o MetaTrader 5 do zero: guia passo a passo

O MetaTrader 5 é a principal plataforma de análise e operação para traders de mini índice, mini dólar, forex e ações no Brasil. Veja como instalar, configurar a corretora e preparar a plataforma para usar o Didi Index.

De onde baixar o MetaTrader 5

O MT5 pode ser baixado diretamente do site da MetaQuotes ou pelo site da sua corretora. A versão da corretora já vem pré-configurada com os servidores dela, o que facilita o login inicial.

Se você já tem conta em uma corretora brasileira (Clear, Rico, XP, Ágora, entre outras), baixe sempre pelo site da corretora para evitar precisar configurar o servidor manualmente depois.

Depois de instalar o MT5, instale o Setup Didi Index com um arquivo só. Bollinger, ADX, Didi Index, Estocástico e TRIX já configurados.

Instalação no Windows

  1. Execute o instalador baixado (mt5setup.exe ou o instalador da corretora).
  2. Aceite os termos e escolha o diretório de instalação. O padrão funciona bem para a maioria dos usuários.
  3. Aguarde a instalação. O MT5 vai abrir automaticamente após concluir.
  4. Na tela de login, informe o número de conta e senha da sua corretora, ou crie uma conta demo para praticar.

Instalação no Mac

O MT5 nativo para macOS existe mas é limitado em recursos. A forma mais confiável é usar o Wine (gratuito) para rodar a versão Windows no Mac. Algumas corretoras também oferecem o MT5 Web, acessível pelo browser sem instalação — útil para quem usa Mac e quer testar antes de configurar o Wine.

Estrutura de pastas: onde ficam os indicadores

Essa é a informação mais importante para quem vai instalar o Setup Didi Index:

  1. No MT5, clique em Arquivo > Abrir Pasta de Dados.
  2. A pasta que abre é o diretório de dados do usuário.
  3. Dentro dela: MQL5 > Indicators é onde você copia arquivos .ex5.
  4. No MT4, a lógica é idêntica, mas a pasta é MQL4 > Indicators e o arquivo é .ex4.

Após copiar o arquivo para a pasta correta, reinicie o MT5 ou clique com o botão direito em "Indicators" no painel Navigator e selecione "Refresh". O indicador vai aparecer na lista e estará pronto para usar.

Adicionar o servidor da corretora manualmente

Se você baixou o MT5 diretamente da MetaQuotes (e não da corretora), precisará adicionar o servidor manualmente:

  1. Acesse Arquivo > Abrir Conta.
  2. Na caixa de busca, digite o nome da sua corretora (ex: "Clear" ou "XP").
  3. O MT5 vai localizar os servidores disponíveis. Selecione o servidor correto e faça login.

Conta demo para praticar

Antes de operar com dinheiro real, use uma conta demo. No MT5, acesse Arquivo > Abrir Conta > Conta Demo. Você opera com dinheiro virtual nos mesmos ativos reais, com dados de mercado ao vivo. É a forma mais segura de aprender a usar os indicadores e testar o setup antes de assumir risco real.
