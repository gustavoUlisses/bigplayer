MetaTrader 4 ou MetaTrader 5: qual usar para o Didi Index?

O MetaTrader 4 ainda é amplamente usado no Brasil para forex. O MetaTrader 5 domina os contratos futuros da B3. Para quem quer usar o Didi Index, entender as diferenças práticas entre as duas versões evita surpresas na instalação.

Diferenças principais entre MT4 e MT5

O MT4 foi lançado em 2005, focado em forex. O MT5 foi lançado em 2010 com suporte a ações, futuros e múltiplos timeframes adicionais (M2, M3, M4, M6, M10, M12, M20).

No Brasil: corretoras de forex costumam oferecer MT4. Corretoras de futuros B3 (WIN, WDO) quase sempre oferecem apenas MT5. Se você opera mini índice ou mini dólar, só o MT5 funciona.

O setup inclui os dois arquivos: .ex4 para MT4 e .ex5 para MT5. Um único pacote, R$29,90, funciona nas duas plataformas.

Indicadores .ex4 e .ex5 não são intercambiáveis

Esse é o ponto mais importante para quem compra o Setup Didi Index: um arquivo .ex4 não funciona no MT5 e vice-versa. Os indicadores são compilados separadamente para cada plataforma.

O pacote inclui os dois arquivos justamente para cobrir os dois casos. Se você usa MT4, instala o .ex4 na pasta MQL4/Indicators. Se usa MT5, instala o .ex5 na pasta MQL5/Indicators.

Qual escolher para forex

Para forex (EUR/USD, GBP/USD, pares com dólar) em corretoras internacionais como XM, Pepperstone, IC Markets: a maioria ainda usa MT4, mas todas oferecem MT5. Se sua corretora oferece MT5, escolha o MT5 — tem mais timeframes, melhor gestão de ordens e desenvolvimento ativo pela MetaQuotes. O MT4 não recebe mais atualizações significativas.

Qual escolher para B3 (WIN, WDO)

Para mini índice e mini dólar no Brasil: obrigatório MT5. O MT4 não tem acesso aos contratos futuros da B3. Todas as corretoras brasileiras que oferecem MetaTrader para futuros usam MT5. Use o arquivo .ex5 do setup neste caso.

Posso ter MT4 e MT5 instalados ao mesmo tempo?

Sim. São programas independentes e podem coexistir no mesmo computador sem conflito. Se você opera forex com uma corretora e futuros B3 com outra, é comum ter os dois instalados. O Setup Didi Index funciona nos dois simultaneamente — instale o .ex4 no MT4 e o .ex5 no MT5.
