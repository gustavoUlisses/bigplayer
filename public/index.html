02 O que é o Didi Index

Uma estratégia visual,
usada há décadas no Brasil

O Didi Index é uma estratégia de análise técnica criada pelo trader Odir Aguiar. A ideia é simples: o gráfico mostra visualmente quando o mercado está prestes a se mover com força. Você não precisa calcular nada, só aprender a ler o sinal na tela. Por isso é uma das estratégias mais usadas por traders brasileiros, do iniciante ao profissional.
